# Hotwire Native Integration - Initial Idea

Implement Hotwire Native to wrap the Langlets Rails web app in native iOS and Android shells using Turbo WebViews. This addresses iOS PWA session/cookie issues while providing a more native-feeling experience.

## Goal
Explore and validate Hotwire Native as a mobile solution for Langlets, as an alternative to PWA.

## Key Points
- Minimal iOS and Android wrapper apps
- Load Langlets via Turbo WebView
- Stable session/auth behavior
- Path Configuration (bundled + remote)
- Most UI stays in Rails; native code is minimal
