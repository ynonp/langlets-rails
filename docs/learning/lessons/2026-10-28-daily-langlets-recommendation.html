Quest: The Journey of a Daily Langlet 📬🎬

🎯 Quest Intro

Flow: From day 6 onwards, each user who joined the "Daily Langlets" starter programme gets one personalised video suggestion per day. It's found with Gemini, imported as a ready course in advance, then announced by email and/or push at the user's chosen local time.

Why it matters: This is the habit loop: it turns a one-time signup into a daily reason to come back, without ever sending an empty or random reminder. Every step is built to survive crashes, duplicate workers and outages.

Trigger: SendDailyChallengesJob, run every 5 minutes (config/recurring.yml:2-4), or the user opening /daily_challenge.

⚠️ Production note: delivery is currently paused (config/environments/production.rb:6), so this lesson also covers how the pause works.
